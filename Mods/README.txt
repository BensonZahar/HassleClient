Hassle Mods
===========
Папка модов на устройстве:
  Android/data/com.hassle.online/files/Mods/

  Mods/arm64-v8a/     - моды для 64-бит (почти все телефоны и Nox x64)
  Mods/armeabi-v7a/   - моды для 32-бит

Как добавить мод: положи файл .so в нужную папку (по архитектуре) и перезапусти игру.
Как убрать мод: удали его .so из папки (из files/mods внутри приложения он сотрётся при очистке данных).
Как обновить мод: замени файл на новый, при запуске он скопируется заново.
Моды грузятся по алфавиту. Лог загрузки: adb logcat -s HassleMods

Эта папка создаётся сама при первом запуске и заполняется из APK.
Этот архив нужен только если автозаполнение не сработало: распакуй его так,
чтобы получилось Android/data/com.hassle.online/files/Mods/arm64-v8a/libHassleExtended.so
